Kết nối API Google Apps Script

Dán URL web app Apps Script (kết thúc bằng /exec) để tải dữ liệu từ Google Sheet.

Lấy URL /exec ở đâu?
Trong Google Sheet → Tiện ích mở rộng → Apps Script → dán Code.gs → Triển khai → Ứng dụng web (Thực thi: Tôi, Truy cập: Bất kỳ ai) → sao chép URL kết thúc bằng /exec. Xem chi tiết trong README.md của repo GitHub.
