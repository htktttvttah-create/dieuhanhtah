# GitHub Pages frontend

Thư mục này chỉ chứa giao diện tĩnh. Cập nhật `config.js` với Google OAuth Web Client ID được cấp và Apps Script `/exec` backend của tổ chức.

**Không thêm dữ liệu thuê bao, file Excel nguồn, `Code.gs` backend, token hoặc mật khẩu vào repository.**

Cách triển khai đầy đủ nằm trong `README-START-HERE.md` ở bộ ZIP chuyển đổi.
